# Warioware Stickslop
- It's a warioware-styled game that I made with 2d pixel stickman art in Godot. The goal is to complete minigames within a time limit and diffculty. Made for Hack Club's stardance.
## Features
- 3 fun minigames with warioware style
- 2 diffculty with mechanics, easy and hard
- 5 lives
- 2D pixel art
## How do I try this?
- [Itch.io](https://nottacos3.itch.io/warioware-stickslop), simply go to the link and press Run Game :)
## How would I run this?
- Import this project to your godot engine!
